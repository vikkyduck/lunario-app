# Цифровая карта в Лунарио

Источник расчета — `Lunario_01_TЗ на нумерологию.docx`, версия 1.0 от 02.10.2026.
Источник 99 карточек — `Lunario_Нумерология.docx`, версия 1.0 от 02.10.2026.
Интеграция выполнена по прямому поручению владелицы использовать эти документы.

`backend/numerology.mjs` реализует отдельные функции R9, R22 и RE, 2 профиля звезды,
числа даты, 4 компонента имени, экспрессию и название бизнеса. Идентификаторы профилей
сохранены из ТЗ. Метод `lunario-numerology-v1` применяет уточнения M02–M05 из ТЗ;
это формализация документа, а не дополнительная внешняя методика. Для 15.10.1990
используется исправленная сумма 26 и результат 8. Личный год, месяц и день не меняются.

Исходные поля 99 карточек извлечены без редакторских изменений скриптом
`tools/import-numerology-docx.py`. SHA-256 исходного DOCX сохранен в JSON.
Миграция 28 загружает каталог в SQLite `numerology_texts` в одной транзакции.
Ключ: версия контента, пространство интерпретаций, раздел, число. Новая версия
текстов должна получать новый contentVersion и отдельную миграцию.
JSON расположен в закрытой серверной папке `backend/data`, в браузер не раздается.
В интерфейсе применяется существующая редакционная замена буквы с двумя точками
на обычную Е; исходные тексты в базе сохранены точно. Введенные имена и таблица
букв эту замену не проходят: Е = 6, U+0401 = 7.

`GET /api/numerology/map` получает дату из анкеты текущей сессии, возвращает только
подходящие карточки и расчет каждого числа. Другой user_id и дата из параметров
запроса не используются. `POST` сохраняет отдельные поля имен и бизнеса в
`users.numerology_data`, зашифрованном штатным AES-GCM, с обновлением data_rev.
Невалидный ввод дает 422 и не заменяет сохраненные поля; корректные независимые
расчеты остаются в ответе. Дата повторно читается из профиля при каждом открытии.
Нет автоподстановки имени обращения из анкеты в официальное имя.

По умолчанию отображается звезда 1–9. Режим 1–22 возвращает только арифметику
с явным сообщением об отсутствии текстов. Экспрессия 11/22 сохраняет значение
и также показывает отсутствие описания. Подстановки 2/4 или трактовок из
другого пространства нет. Каталог не отправляется сторонним сервисам.

Поля цифровой карты сохраняются при очистке истории, включены в личную выгрузку
JSON/PDF и удаляются вместе с аккаунтом. Смена аккаунта отменяет запросы и очищает
экран. При сохранении форма блокируется до ответа, чтобы не потерять новый ввод.

Проверки: `node tools/check-numerology.mjs` — примеры ТЗ, все 73 049 дат
1900–2099 годов в обоих профилях, Unicode, шифрование, изоляция HTTP-сессий,
сохранение, экспорт, удаление, отсутствие полного каталога в публичных файлах,
неизменность личного года. Включено в `tools/check-all.mjs`.
