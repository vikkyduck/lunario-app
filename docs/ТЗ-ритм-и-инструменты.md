## 23.0 Коротко

Лунарио живёт **ритмом из трёх моментов**, а не каталогом функций:

| Момент | Пуш | Что делает Лунарио | Что делает человек |
|---|---|---|---|
| **Утро** | 09:00 | «На что обратить внимание сегодня»: установка дня, тема дня через выбранный источник, «Сохранить себе на экран» | читает 20–30 секунд, ничего не обязан |
| **Вечер** | 21:00 | «Запомнить этот день»: одно поле + настроение, благодарность, привычки, аскеза, ответ на вопрос дня — всё на одном экране | отмечает то, что хочет; день сохранён после любого действия |
| **Воскресенье** | 13:00 | «Моя неделя»: настроение, что сохранили, что отозвалось, ритм, одна рефлексия | смотрит, сам отмечает, что отозвалось |

**Пушей ровно три.** Человек настраивает только их — время и включён/выключен — в Аккаунт → Уведомления. Поштучных напоминаний (карта, лунный день, привычки, аскеза, благодарность, настроение, небо, отчёт) больше нет: всё, что человек заполняет вечером, приходит **одним** вечерним пушем, а не россыпью. Текст пуша — одна короткая строка, без приписок и подсказок.

**Инструменты** человек выбирает сам: стартовый набор маленький, каталог — в один тап из раздела. Убрать инструмент — не потерять записи.

Формула: *утром Лунарио предлагает тему для наблюдения, вечером помогает сохранить важное, в конце недели возвращает человеку его неделю.*

Правила (они же критерии приёмки):

1. Вечер — не чек-лист. Нет «3 из 4», процентов, красных пропусков, незакрытого ритуала, серий «N дней подряд» на главной.
2. Утром — «обратите внимание на…» и **рекомендация**, не «предсказание» и не «прогноз». Вечером никто не проверяет «точность».
3. В неделе — «что отозвалось», не «что совпало». Связь подтверждает человек.
4. Добавление инструмента не включает напоминания. Удаление не стирает записи.
5. Каждый тип данных хранится своим типом: настроение, благодарность, запись, ответ на вопрос, отметка привычки, день аскезы — разные таблицы, как сейчас. Одна кнопка «Запомнить этот день» — не одна универсальная запись.
6. Три пуша, короткий текст. Ничего в пуш не дописываем.

Сейчас перестраиваются только **«Сегодня»** и **«Дневник»**. «Свериться с собой» и «Обо мне» не трогаем.

## 23.2 Ревизия ежедневных функций «Сегодня» и «Дневника»

Куда уходит каждая функция, что есть сейчас. «Инструмент» — плитка по выбору из каталога.

| Сейчас на экране | Куда идёт | Примечание |
|---|---|---|
| Установка дня (`#h-wish`) | **Утро**, всегда | |
| Вопрос дня (`tone`) | **Утро** показывает вопрос (источник «вопрос к себе»), **вечер** — поле ответа | связь утро→вечер: рефлексия, о которой просила владелица |
| Карта дня | **Утро**, если выбран источник «карта дня» | не на старте |
| Лунный день (рекомендация, темы, полоска 30 дней) | **Утро** — тема и рекомендация, если выбран источник; полный экран с полоской — инструмент | источник по умолчанию |
| На небе (транзиты) | **Утро**, если выбран источник; полный экран — инструмент | |
| Прогноз дня по знаку (4 шкалы) | **инструмент**, не в утре | владелица: «ключевое — не прогноз, а рекомендация»; выключен на старте |
| Аффирмация («настрой дня», 12 фраз) | **Утро** — на карточку, как «установка дня» (решение владелицы); связать с общим прогнозом — см. 23.4 | открытый вопрос: две сущности — 365 установок с именем и вопросом и 12 настроев |
| Отметить настроение (быстрое действие) | **Вечер** | быстрое действие с главной убирается |
| Записать мысль (быстрое действие) | **Вечер** — главное поле, с теми же подсказками и диктовкой | подсказки и микрофон переезжают в вечер |
| Задать вопрос (быстрое действие → Свериться) | убирается с главной | «Свериться» не трогаем; там всё остаётся |
| Мой ритуал («0 из 3», «Продолжить мой день») | **растворяется**: практики — инструменты, счётчик — нет | решение владелицы |
| Дневник привычек | **Вечер** — чекбоксы только на сегодня; ведение (добавить, ритм, календарь) — **инструмент** | **награды за серии удаляются** (решение владелицы: не вяжется с концептом) — `habit_awards`, `награды.txt`, экран наград |
| Взять аскезу | **Вечер** — «держусь / сорвалась» + заметка; взять/остановить — **инструмент** | фразы поддержки (`поддержка-аскезы.txt`) удаляются; про темп скажет «Моя неделя» |
| Дневник благодарности | **Вечер** — своя ячейка «Кому и за что вы благодарны?»; история — в ленте | |
| Лента записей с фильтрами | **Дневник**, как есть | + фильтр «Итоги недели» |
| Мои желания (с фото) | **инструмент** в Дневнике | не ежедневная; исполненные за неделю попадают в «Мою неделю» |
| История настроений (неделя/месяц) | неделя — в **«Мою неделю»**; месяц — **инструмент** в Дневнике | |
| Мои вопросы и ответы, карты дня | **Дневник**, лента и инструмент | |
| Итоги недели | становится **«Моя неделя»** | |
| Открытки (установка, настроение, лунный день, небо, привычки, аскеза) | утро — «Сохранить себе на экран»; остальные — внутри инструментов | открытка недели — позже |
| Приглашение включить уведомления на главной | заменяется экраном **«Ритм»** (три переключателя) | |
| Серия дней (`touchStreak`) | нигде не показывается | правило 1 |

## 23.3 Конструктор инструментов

- `users.preferences.tools` — JSON-массив ключей **видимых** инструментов (ключи из `FEATURES`, они же в напоминаниях и событиях, не меняются). Нет поля → стартовый набор.
- Инструмент либо **служебный** (профиль, уведомления, инструменты, данные, поддержка — не отключается), либо **выбираемый**.
- Видимость — только видимость: таблицы, маршруты, история не трогаются. Вернул — записи на месте. Ничего не грузится модулями: каталог ставит `hidden` плиткам по `data-feature`.
- Добавление не включает напоминания — их три и они настраиваются отдельно.

### Стартовый набор («Сегодня» и «Дневник»)

| Раздел | На старте | В каталоге |
|---|---|---|
| Сегодня | Утро (установка + тема дня через лунный день) · «Запомнить этот день» | Привычки, Аскезы, Прогноз по знаку, Лунный день (полный), На небе |
| Дневник | Лента записей · «Моя неделя» | Желания, История настроений (месяц), Мои вопросы и ответы |

Утро и вечер — это не инструменты, а ритм: их не убрать. Внутри утра — **источник темы дня** (настройка, см. 23.4). Стартовый набор — гипотеза; меняется строкой в `content/инструменты.txt` без выпуска кода.

### Каталог

Панель `w-tools` («Все инструменты»), открывается из ссылки «Выбрать инструменты» под плитками раздела и из Аккаунт → Приложение → «Мои инструменты». Карточка:

```
Дневник привычек                                        [Добавлено ✓]
Свой ритм и ежедневные отметки; вечером —
галочки только на сегодня.
Посмотреть пример · Убрать
```

«Добавить», не «Подключить». «Посмотреть пример» открывает сам инструмент. Тексты — `content/инструменты.txt`: `ключ | раздел | название | описание | на старте (да/нет)`. Платных инструментов пока нет; появятся — в той же строке `бесплатно / в подписке`, и это видно до «Добавить».

## 23.4 Утро · «На что обратить внимание сегодня»

Блок сверху «Сегодня»:

1. **Установка дня** — и её нужно **связать с общим прогнозом** (тоном дня). Сейчас в контенте три независимых случайных выбора: тон дня (`тона-дня.txt`, 12 тонов — «День границ», «День решений»…), установка с именем и вопросом (`установки.txt`, 365 строк в 12 тематических блоках) и настрой (`аффирмации.txt`, 12 фраз). Предложение: один **ключ темы** на все три файла (12 тем); утро сначала выбирает тон дня, а установку и вопрос — только из блока той же темы (без повторов за год, как сейчас). Тогда «День границ» → «Я не обязана нравиться всем» → «От чего сегодня стоит отказаться?» читаются как одно. Разметку ключей по трём файлам я делаю черновиком, владелица правит. Вопрос владелице: на карточке одна строка — установка с именем (365) — а 12 настроев становятся второй строкой тона? или наоборот?
2. **Тема дня** — короткая рекомендация через выбранный источник: **лунный день** (по умолчанию) · **карта дня** · **руна дня** · **транзиты** (что на небе) · **вопрос к себе сегодня**. Один источник, выбирается в Аккаунт → Уведомления → Утро (там же время). Карта или руна дня показывается плиткой прямо в блоке, если выбрана.
3. **«Сохранить себе на экран»** — открытка: установка + тема + аффирмация (как сейчас у установки).

Никаких полей ввода. Слова «предсказание» и «прогноз» в утре не используются.

- `preferences.morning` — ключ источника (`lunar` по умолчанию). Тема дня считается на сервере: `dayPack().theme = { source, title, text, image? }` — из лунного дня (первая фраза выбранных тем чтения, как в нынешнем пуше), карты (`entries` kind `card`, тянется утром, как сейчас), руны (новое: `entries` kind `dayrune`, одна руна в день, те же тексты `руны.txt`), неба (первое событие + пояснение из `небо.txt`), вопроса дня.
- **Пуш `morning`**: одна строка — тема дня по источнику («Обратите внимание: …»). Deep link `?open=morning`. Текст — `напоминания.txt`, ключи `morning-lunar`, `morning-card`, `morning-rune`, `morning-sky`, `morning-question`; подстановки как в нынешних `lunar`/`sky`/`card`.

## 23.5 Вечер · «Запомнить этот день»

Панель `w-evening` — один экран, **ячейки-вопросы**, каждая со своим вопросом вместо подсказки. Никаких переключателей и «+ полей»: человек отвечает на те, на которые хочет, и ответы сами ложатся в свои типы данных.

```
Запомнить этот день

Что было важным сегодня? Что стоит запомнить?
[ поле ]  ← растёт; микрофон; чипы-подсказки «Что произошло?» «Что я почувствовала?»

Кому и за что вы сегодня благодарны?
[ поле ]

Вопрос дня: «Что в сегодняшней задаче на самом деле простое?»
[ поле ]

Настроение   [спокойно] [устала] [радость] [тревога] [благодарность] [все оттенки…] [своё слово +]
             ← можно отметить несколько, хоть все, и написать несколько своих
Привычки     ☐ Прогулка   ☐ Вода                       ← только те, что должны быть сегодня
Аскеза       Без скроллинга · день 7 из 14  [держусь] [сорвалась]  [заметка]

                                    [ Запомнить этот день ]
```

- Три текстовые ячейки — три типа: запись (`journal.kind=''`), благодарность (`gratitude`), ответ на вопрос дня (`answer`, `title` = вопрос). Текст хранится целиком, предложением самого человека — ничего не режется и не разбирается.
- Строки настроения, привычек и аскезы показываются только для подключённых инструментов и только если есть что отмечать. Ни одна ячейка не обязательна; пустая не сохраняется.
- **Несколько настроений** — таблица «отметки настроения» (день → несколько строк), первое отмеченное остаётся «главным» в старой строке; своих слов можно написать несколько (каждое — `own:…`). Человеку это не видно.
- **Фраз поддержки аскезы нет** (решение владелицы): про соблюдение аскезы и темп скажет «Моя неделя».
- Открылся вечером — уже видно, что сохранено: отметки за сегодня подсвечены, поле с текстом дня. Никаких «осталось 2».
- После «Запомнить этот день» — «День сохранён ✦», тихая строка «Можно дополнить до полуночи». Ничего не отметил — ничего не должен.
- **Данные — разными типами, одним запросом.** `POST /api/evening` `{ text, gratitude, moods[], habits[], askesis[{id,kept,note}], answer }` пишет в одной транзакции в `journal` (kind `''`, `gratitude`, `answer`), `moods` + `mood_marks`, `habit_marks`, `askesis_days` — через уже существующие функции. `GET /api/evening?day=` — состояние дня. Атомарность и офлайн-повтор — ради этого один запрос; таблицы — раздельные.
- **Пуш `evening`**: «Что хочется оставить от этого дня?» — одна строка. Подавляется, если за сегодня уже есть любая вечерняя запись. Deep link `?open=evening`.
- Карточка «Запомнить этот день» на главной доступна весь день; с 17:00 поднимается выше утра.

## 23.6 Воскресенье · «Моя неделя»

Виджет `week` перестраивается (`/api/week` расширяется, адрес прежний):

1. **Настроение недели** — по дням, все отмеченные оттенки, без оценок.
2. **Что вы сохранили** — 2–3 фрагмента из записей и благодарностей, дословно; исполненные желания за неделю.
3. **Что отозвалось** — пары «утром: тема дня ↔ вечером: запись» по дням с отметкой **Отозвалось · Не связано · Не уверена** → таблица `week_echoes(user_id, day, verdict, ts)`. Лунарио не пишет «совпало».
4. **Ваш ритм** — дни с отметками привычек и аскез точками, без «дисциплины».
5. **Одна рефлексия** — «Что хочется взять с собой в следующую неделю?» → `journal.kind = 'weekly'`, необязательно.

Мало данных (< 3 записей) — короткий экран «На этой неделе вы сохранили 2 момента · Посмотреть их вместе». Ничего — «Записей не было. Это нормально».

**Пуш `week`**: вс 13:00 — «Ваша неделя в Лунарио готова» / при малых данных — «На этой неделе вы сохранили 2 момента». Deep link `?open=week`.

## 23.7 Три пуша вместо восьми

- `REMINDER_FEATURES` = `morning`, `evening`, `week`. Старые ключи (`card`, `mood`, `moodreport`, `habits`, `askesis`, `gratitude`, `lunar`, `sky`) **удаляются** из реестра и из экрана «Уведомления».
- Перенос настроек один раз при выпуске: было включено хоть одно утреннее (`card`, `lunar`, `sky`) → `morning` с самым ранним временем; хоть одно вечернее (`mood`, `habits`, `askesis`, `gratitude`) → `evening` с самым поздним; `moodreport` → `week` с тем же днём и временем. Строки старых напоминаний в базе не удаляются — лишний раз ничего не терять.
- Аккаунт → Уведомления: три строки — Утро (время, источник темы дня), Вечер (время), Неделя (день, время). Больше ничего.
- Тексты пушей — одна строка, без приписок. Экран «Ритм» при первом входе — единственное место, где пуши предлагаются сами (три переключателя, «Включить», можно пропустить).

## 23.8 Данные и миграции

- `users.preferences.tools`, `preferences.morning` — без миграции (JSON в существующем поле).
- `mood_marks(user_id, day, mood, PRIMARY KEY(user_id, day, mood))` — миграция 13. `moods.mood` = первое отмеченное.
- `week_echoes(user_id, day, verdict, ts, PRIMARY KEY(user_id, day))` — миграция 14.
- `journal.kind = 'weekly'`, `entries.kind = 'dayrune'` — колонки текстовые, миграции нет; экспорт и PDF показывают их словами.
- Миграции идемпотентные, только добавляют; откат выпуска безопасен.

## 23.9 Экраны

- **Сегодня:** утренний блок → «Запомнить этот день» → плитки подключённых инструментов → «Выбрать инструменты». Быстрых действий и «Моего ритуала» нет.
- **Дневник:** «Моя неделя» первой плиткой по вс и пн, дальше лента; «Желания и итоги» — подключённые инструменты + «Выбрать инструменты».
- **Аккаунт → Приложение:** «Уведомления» (три пуша) и «Мои инструменты».
- **Первый вход:** после анкеты — экран «Ритм».
- Пуши ведут на свой экран через `openTarget()`: `?open=morning|evening|week`.

## 23.10 Контент

- `content/инструменты.txt` — карточки каталога и стартовый набор.
- `content/напоминания.txt` — ключи `morning-*`, `evening`, `week`, `week-мало`, `week-пусто`; старые ключи убираются.
- `content/вопросы-недели.txt` — вопросы для рефлексии по кругу.
- Правило про служебные ключи — в `ПРОЧТИ-МЕНЯ.txt`.

## 23.11 Аналитика

События: `tools_add`, `tools_remove`, `morning_view`, `morning_source`, `evening_open`, `evening_save` (детали `text|gratitude|mood|habits|askesis|answer`), `week_view`, `echo_mark` (`yes|no|unsure`), `rhythm_enable`. Отчёт «Ритм» в кабинете: доля людей с ≥1 и ≥3 вечерами в неделю, доля с тремя пушами, распределение «отозвалось / не связано / не уверена». Без текстов.

## 23.12 Чего не делаем

Платные уровни; ИИ-интерпретация недели; модульная загрузка; изменения нижней навигации; «Свериться с собой» и «Обо мне» — не трогаем.
