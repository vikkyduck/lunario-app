# Лунарио — веб-приложение

Пространство, где можно услышать себя: карта дня, ответы на вопросы («Да/Нет», руны,
расклад «Три карты»), прогноз по знаку, нумерология, дневник, настроение и серия
дней. Живёт на **https://lunario.online/app/** и ставится на телефон как PWA.

## Как устроено

Без фреймворков и зависимостей — чинится одним человеком по SSH:

- `site/` — весь фронтенд: один `index.html` (ванильный JS, экраны-«view»),
  service worker, манифест PWA.
- `backend/server.mjs` — весь бэкенд: Node ≥ 22.5, база `node:sqlite`,
  анонимный аккаунт по куке + вход по коду на почту, шифрование личных записей
  (AES-256-GCM), лимиты, платежи Продамус (вебхук), веб-пуши, статистика `/stats`.
- `site/cabinet.html` + `backend/cabinet.mjs` + `backend/reports.mjs` — рабочие
  кабинеты `/app/cabinet`: роли по почте (админ, маркетолог, продуктолог, контент,
  поддержка), единый дашборд и отчёты по каждой роли из тех же таблиц, что и
  приложение. Личных текстов в кабинетах нет; у показателя три состояния — число,
  «нет данных», «не запущено». Два админа заданы почтой (`ADMIN_EMAILS`) и защищены.
- `backend/workspace.mjs` — то, что сотрудники вносят сами: кампании и UTM (маркетолог),
  материалы со статусами и картинки (контент; опубликованный «вопрос дня» подменяет текст
  в приложении), ключи ИИ-провайдеров и беклог задач (продуктолог), обращения и чат
  с пользователем + SLA (поддержка). Тексты чата и ключи ИИ шифруются тем же ключом, что дневник.
  Картинки лежат в `data/uploads/` и отдаются по `/app/uploads/…`.
- `backend/shelves.mjs` — «полочки»: досье каждого человека из трёх полок — «Обо мне» (анкета, знак,
  числа, личный год, Солнце/Луна/Асцендент), «Мой день» (настроение, карта дня, неделя, дневник, желания,
  привычки, аскезы), «Истории» (обращения, темы, ответы). Пересобирается после каждого действия из тех же
  таблиц, что и экраны, хранится зашифрованным. Человек видит его в «Аккаунт → Мои данные» (`GET /api/shelves`);
  разборы и гороскопы берут отсюда контекст (`GET /api/shelves/context` — досье текстом, без почты).
- `backend/backup.mjs` — резервные копии: база приложения, ключ шифрования, ключи пушей и папка
  контента, 14 последних в `BACKUP_DIR` (`/opt/lunario-app-backups`). Ночью запускает cron
  (`/etc/cron.d/lunario-app-backup`, ставится `deploy.sh`), днём — кнопка «Снять копию сейчас»
  в кабинете админа на странице «Здоровье системы», там же список и скачивание.
- `backend/astro.mjs` — эфемериды без зависимостей. Планеты и Хирон 1920–2080 — таблица видимых
  долгот из JPL Horizons (`backend/ephem.bin`, ~1 МБ, собирается `tools/build-ephem.mjs`; точность
  ~1″), Солнце и Луна — ряды Меёса (сверено с JPL: 1–2″), узел оскулирующий, Лилит — средний
  апогей, Селена — 7-летний цикл, Парс Фортуны (дневная/ночная формула), Вертекс, дома Плацидуса
  (за полярным кругом — Порфирий), аспекты. Вне таблицы — кеплеровы элементы (±1′), Хирона нет.
  `GET /api/natal` считает карту по анкете на лету; время рождения переводится в UTC через часовой
  пояс города (IANA, с историей).
- `content/` — тексты и картинки приложения: `.txt`-файлы (карты, руны, знаки,
  нумерология, личный год, аффирмации) и папка `картинки/`. Это не код: в git лежит
  только `content/ПРОЧТИ-МЕНЯ.txt` с описанием формата, остальное игнорируется.
  На сервере контент живёт в `/opt/lunario-content` (переменная `CONTENT_DIR`),
  локальная `content/` — рабочая копия: `./тексты-с-сервера.sh` забирает,
  `./обновить-тексты.sh` отправляет; сервер перечитывает без перезапуска, картинки
  отдаются по `/app/content/<вид>/<файл>`.
  Карты Таро (22) и руны (28) лежат «книгой» с разделами и картинками; карта дня тянется случайно раз в день,
  руны и расклады (три руны, крест, четыре стихии; три карты, «Выбор», Кельтский крест) —
  каждый раз заново, всё ложится в историю. Результат можно скачать открыткой 9:16
  (canvas → `navigator.share` / загрузка / в оболочке iOS — системное меню через мост).
  Открытки есть и у настроения, отчёта по настроениям, привычек, аскезы, лунного дня и неба.
- «Мой день»: **Дневник привычек** (регулярность своими словами — «каждый день», «по будням», «пн и чт»,
  «3 раза в неделю»; карточка дня с галочками; награды за 30 · 60 · 90 · 180 · 365 дней подряд для ежедневных),
  **Взять аскезу** (отказ или ограничение до выбранной даты, поддержка и счёт дней, заметки по желанию),
  **Дневник благодарности** («Кому и за что я благодарна сегодня?» — запись с датой уходит в дневник),
  **Вопрос дня** к установке дня (`content/установки.txt`, 365 штук, без повторов за год у каждого),
  **Настроение дня** по кругу Плутчика (32 оттенка). Дневник живёт в «Истории».
- Главная: шесть квадратов, шестой — **Новое в приложении** (`content/новое.txt`, плитки ведут в разделы);
  вместо пожелания — установка дня с именем; фото в кружке аккаунта. У желаний — фото для визуализации.
- Все тексты, которые видит человек, живут в папке контента: небо (`небо.txt`), эмоции (`эмоции.txt`),
  тексты напоминаний (`напоминания.txt`), поддержка аскезы, награды за привычки, плашки-запросы. В коде — только
  запасные значения на случай отсутствия файла.
- `backend/reminders.mjs` + `backend/send-daily.mjs` — напоминания по функциям: карта дня, настроение,
  отчёт по настроениям, привычки, аскеза, лунный день, небо. У каждого своё время и регулярность
  (каждый день, по будням, раз в неделю; у неба — «когда что-то происходит»), в часовом поясе человека.
  Таймер `lunario-daily.timer` раз в 5 минут: тексты кладутся в очередь `push_queue`, в браузер уходит
  пустой сигнал, service worker забирает тексты с `/api/push/next` по куке — через чужие почтовые службы
  личное не летит. В оболочке App Store те же настройки становятся локальными уведомлениями телефона
  (`NativeBridge.swift`, сообщение `schedule`).
- `backend/sky.mjs` — «На небе»: фазы Луны с точностью до минут, затмения (по узлам), ретроградность
  Меркурия, Венеры, Марса, Юпитера, Сатурна, вход Солнца в знак, точные аспекты дня; события на 60 дней вперёд.
- `mobile/` — обёртка TWA для магазинов Android + инструкция
  `КАК-ВЫЙТИ-В-МАГАЗИНЫ.md`.
- `tools/` — служебные скрипты (скриншоты, сборка базы городов).

## Запуск локально

```bash
PORT=5031 BASE_PATH=/app DATA_DIR=./data node backend/server.mjs
# открыть http://localhost:5031/app/
```

Подсказки городов используют `backend/cities.db` (в репозиторий не входит —
собирается из данных [GeoNames](https://www.geonames.org/), CC BY 4.0):

```bash
node tools/build-cities.mjs /путь/к/выгрузке-geonames
```

Почта, платежи и статистика включаются переменными окружения на сервере
(`set-smtp.sh`, `set-pay.sh`, `set-stats.sh`) — в коде секретов нет.

## Деплой

`bash deploy.sh` — код (`site/`, `backend/`) rsync'ом на сервер + systemd; контент
едет отдельно — `./обновить-тексты.sh`. Перед выкаткой из нескольких
рабочих копий: `bash deploy-safe.sh <снимок-прода>` сверит сервер со снимком
и не даст затереть чужие правки.

## Принципы

- Данные пользователей хранятся в России (152-ФЗ), личные записи шифруются,
  в аналитику уходит только тип события — без текстов.
- Статика бесплатна и безлимитна; платное показывается честно, с ценой,
  ещё не включённое — с бейджем «скоро» и записью интереса вместо оплаты.
- Тексты — на «вы», без гарантий и запугивания.
